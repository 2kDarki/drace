# Z229 — Unstable Return API

## What it targets

Functions that return too many different shapes or types.

## Why it exists

Highly variable returns create brittle callers and unclear contracts.

## What it encourages

- Consistent return forms
- Explicit success/error channels
- Predictable API boundaries

## What it does NOT say

- It does not forbid polymorphism
- It does not require one single return type always
- It warns about API instability pressure
