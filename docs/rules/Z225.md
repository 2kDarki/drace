# Z225 — Overloaded Data Structures

## What it targets

Data structures that accumulate too many unrelated concerns.

## Why it exists

Overloaded containers become hard to reason about and harder to evolve safely.

## What it encourages

- Smaller, purpose-specific structures
- Clear ownership boundaries
- Better decomposition choices

## What it does NOT say

- It does not ban dictionaries or rich models
- It does not enforce a single size limit for all contexts
- It flags complexity pressure only
